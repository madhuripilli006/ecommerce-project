# E-Commerce Web Application

## Project Overview
This is a full-stack E-Commerce web application built using React, Node.js, Express, and MySQL. It allows users to register, login, browse products, add items to cart, and place orders.

---

## Features
- User Authentication (JWT)
- User Registration & Login
- Product Listing
- Search Products
- Category Filter
- Sort Products
- Add to Cart
- Remove from Cart
- Place Orders
- Order History
- Responsive Dark UI
- Modern Frontend Design

---

## Technologies Used

### Frontend
- React.js
- Bootstrap
- Axios
- React Router DOM
- React Toastify

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication
- JWT (JSON Web Token)
